# Documentação do ambiente

Esta pasta reúne os **tutoriais de instalação e configuração do ambiente** usado nas atividades práticas de **Interconexão de Redes de Computadores (IRC)**. Faça-os **antes** do primeiro laboratório: o ambiente é preparado uma única vez e depois cada laboratório se resume a importar um projeto.
